# Bitácora de aportes

Historia cronológica del proyecto, escrita por cada agente (o persona) al terminar un aporte. Reglas en [`AGENTS.md`](../../AGENTS.md).

- Una entrada por aporte, con nombre `AAAA-MM-DD-NN-tema.md`; el orden alfabético es el cronológico.
- Las entradas no se editan después; las correcciones van en una entrada nueva.
- La foto actual del proyecto está en [`docs/ESTADO.md`](../ESTADO.md).
- Plantilla: [`_plantilla.md`](_plantilla.md).
