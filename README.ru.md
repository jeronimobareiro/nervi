# Nervi

[Español](README.md) · [English](README.en.md) · [Português](README.pt.md) · **Русский**

Свободное программное обеспечение с открытым исходным кодом для расчёта и проектирования строительных конструкций: вычислительное ядро на Rust и прикладной слой на Python.

Сайт: **[jeronimobareiro.github.io/nervi](https://jeronimobareiro.github.io/nervi/)**.

> **Состояние: этап 1 (линейно-упругий расчёт плоских рам) и предварительная версия настольного интерфейса.** Проектирования по нормам и поддержки IFC пока нет. См. [дорожную карту](docs/hoja-de-ruta.md) (на испанском).
>
> Программа помогает инженеру, но не заменяет его профессиональное суждение и ответственность. Всегда проверяйте результаты.

## Код написан на испанском, но мы рады вам

Nervi появился в Латинской Америке, поэтому код, комментарии и техническая документация написаны на испанском. Это не должно мешать вам участвовать:

- **[Глоссарий](docs/glosario.md)** переводит все строительные термины и имена из кода на русский, английский и португальский (`barra` = стержень, `nudo` = узел, `apoyo` = опора, `caso de carga` = загружение, `momento flector` = изгибающий момент…).
- **Issues, pull requests и обсуждения можно писать на русском, английском или португальском.** Сопровождающие ответят на вашем языке (при необходимости с помощью перевода).
- При ревью мы поможем привести новые имена к испанской терминологии кода.
- Формулы, нормы (ACI, AISC, Еврокоды, СП…) и математика везде одинаковы.

См. [руководство для участников](CONTRIBUTING.md#contributing-from-other-countries).

## Что умеет сейчас

- Плоские рамы из стержней Эйлера–Бернулли (3 степени свободы в узле).
- Узловые нагрузки и нагрузки на стержни: равномерно распределённые, сосредоточенные, трапециевидные и на части пролёта, в местных или глобальных осях; температурные воздействия.
- Шарниры и освобождения связей на концах стержней; фермы.
- Жёсткие и упругие опоры, заданные осадки.
- Несколько загружений с одной факторизацией и линейные сочетания (сочетания и огибающие по ACI 318-19, экспериментально).
- Опорные реакции, концевые усилия, эпюры `N`, `V`, `M` и деформированная схема, включая точки максимального момента.
- Обнаружение механизмов (изменяемых систем) и проверка входных данных с понятными сообщениями.

Опоры учитываются разбиением степеней свободы (без метода штрафа), система решается разреженным разложением Холецкого из [`faer`](https://github.com/sarah-quinones/faer-rs). Рама из 8 100 стержней рассчитывается примерно за 45 мс (сборка release).

## Пример

API использует испанские имена; в комментариях дан перевод.

```python
import nervi

m = nervi.Modelo()                                         # модель
a = m.agregar_nudo(0, 0)                                   # добавить узел
b = m.agregar_nudo(6, 0)
viga = m.agregar_barra(a, b, E=2.5e7, A=0.125, I=2.6e-3)   # добавить стержень (балку), кН, м
m.apoyar(a, ux=True, uy=True, rz=False)                    # шарнирно-неподвижная опора
m.apoyar(b, ux=False, uy=True, rz=False)                   # шарнирно-подвижная опора
m.carga_uniforme("D", viga, qy=-20)                        # равномерная нагрузка вниз, кН/м, постоянная
m.carga_uniforme("L", viga, qy=-10)                        # временная нагрузка

res = m.resolver()                                         # рассчитать
combo = res.combinar("1.2D+1.6L", {"D": 1.2, "L": 1.6})    # сочетание
print(combo.reacciones[a])                 # реакции [Rx, Ry, Mz]
print(combo.diagrama(viga)["M"].max())     # 0,125 · 40 · 6² = 180 кН·м
```

Другие примеры — в [`examples/`](examples/). Правило знаков — в [`docs/convenciones.md`](docs/convenciones.md).

### Настольный интерфейс (предварительная версия)

```
pip install "nervi[gui]"       # или из исходников: pip install PySide6-Essentials
nervi-gui                      # или: python -m nervi.gui проект.nrv
```

Вся работа идёт в одном окне: таблицы узлов, стержней, опор, нагрузок и сочетаний, расчёт по F5, эпюры N, V, M и деформированная схема со значениями под курсором, свойства выделенного, проверка модели, консоль Python и палитра команд (Ctrl+K). Проекты сохраняются в формате [`.nrv`](docs/formato-nrv.md). Установщики для Windows (`.exe`) и Linux (AppImage) собираются в [Releases](https://github.com/jeronimobareiro/nervi/releases) при публикации тега `v*`; они не подписаны. Пока интерфейс только на испанском.

> **Предварительная версия, не для реальных проектов.** Линейно-упругий расчёт проверен на аналитических решениях; проектирования по нормам пока нет.

## Сборка из исходников

Требования: стабильный Rust и Python ≥ 3.10.

```bash
python -m venv .venv && source .venv/bin/activate
pip install maturin pytest
maturin develop --release
pytest
cargo test -p nervi-core
```

## Структура

```
crates/nervi-core/   ядро МКЭ на чистом Rust (без Python)
  src/elemento.rs     жёсткость, преобразование координат, эквивалентные нагрузки, освобождения
  src/analisis.rs     сборка, решение, реакции, эпюры
  tests/verificacion.rs  сравнение с аналитическими решениями
crates/nervi-py/     мост PyO3 (контракт в docs/contrato-datos.md)
python/nervi/        пакет Python
tests/              тесты Python API
verification/       верификационные примеры в TOML, без знания Rust
docs/               техническое задание, соглашения, контракт данных, глоссарий
sitio/              сайт
```

## Верификация

Каждый пример в `crates/nervi-core/tests/verificacion.rs` и `verification/` сравнивается с решением в замкнутой форме или опубликованным примером: консоли, шарнирно опёртые, защемлённые и неразрезные балки, внецентренная сосредоточенная сила, рама с горизонтальной нагрузкой, ферма, наклонные стержни, осадки, упругие опоры, шарнирно-консольная балка, общее равновесие многоэтажной рамы и обнаружение механизмов.

**Правило для участников:** каждая новая функция сопровождается верификационными примерами и источником каждой формулы (см. [`CONTRIBUTING.md`](CONTRIBUTING.md)).

## Как помочь

Nervi открыт для студентов, преподавателей, исследователей и инженеров со всего мира. Начните с [руководства для участников](CONTRIBUTING.md#contributing-from-other-countries) и [глоссария](docs/glosario.md). Задачи с меткой `buen-primer-aporte` подходят для первого вклада; `proyecto-academico` и `tesis-posible` отмечают темы размером с курсовую работу или диссертацию. Правила общения — в [Кодексе поведения](CODE_OF_CONDUCT.md), правила принятия решений — в [`GOVERNANCE.md`](GOVERNANCE.md). Если вы нашли неверный результат, который может повлиять на реальное сооружение, следуйте [`SECURITY.md`](SECURITY.md).

Для цитирования Nervi в научных работах используйте [`CITATION.cff`](CITATION.cff).
