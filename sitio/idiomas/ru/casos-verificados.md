# Проверочные примеры

Nervi не просит верить ей на слово: каждый вид расчёта сравнивается с известным решением, и это сравнение выполняется автоматически при каждом изменении программы. На этой странице описано, как устроена проверка, и перечислены примеры, которые есть в библиотеке сейчас.

## Как проводится проверка

- Каждый пример — это текстовый файл с моделью, ожидаемыми результатами и **источником**: замкнутая формула, учебник с указанием страницы и номера примера или решение, полученное вручную в точной арифметике.
- Автоматическая проверка на GitHub решает все примеры при каждом вкладе и становится красной, если какое-либо значение отклоняется от ожидаемого сильнее допуска (по умолчанию относительная погрешность 1e-9).
- Помимо этого, у расчётного ядра есть десятки аналитических тестов на Rust (механизмы, пространственная рама, динамика, жёсткие вставки и диски перекрытия) и сотни тестов на Python (формат файла, интерфейс, расчётная записка и проектирование).
- Модули **проектирования железобетона** (ACI 318-19) проверены ручными расчётами и сравнением с программами с открытым кодом, но пока не на опубликованных примерах и без проверки инженером-конструктором, поэтому они помечены как экспериментальные.

## Как добавить пример

Чтобы добавить пример, не нужно знать Rust и менять расчётное ядро: достаточно написать текстовый файл. Решённый пример из учебника вашего курса — отличный первый вклад. Инструкции есть в [README библиотеки](https://github.com/jeronimobareiro/nervi/blob/main/verification/README.md) и в разделе [как принять участие](participar/index.md).
