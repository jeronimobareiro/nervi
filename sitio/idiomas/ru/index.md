# Nervi { .nv-oculto }

<div class="nv-portada" markdown>

<p class="nv-lema">Свободная программа для расчёта конструкций.</p>

Nervi рассчитывает рамы методом конечных элементов и показывает реакции опор, внутренние усилия и перемещения. Программа бесплатная, с открытым кодом, а каждый результат сверяется с известным решением.

!!! warning "Предварительная версия, не пригодна для проектирования"
    Nervi находится в разработке. Сейчас программа рассчитывает плоские рамы линейным упругим расчётом; проектирование по нормам пока не реализовано. Она помогает инженеру, но не заменяет ни его суждение, ни его подпись.

## Что программа умеет сейчас

- **Плоские рамы** со стержнями, шарнирами, фермами, жёсткими и упругими опорами и осадками опор.
- **Нагрузки** на узлы и стержни: равномерные, сосредоточенные, трапециевидные и частичные.
- **Загружения и сочетания нагрузок**, например 1.2D + 1.6L.
- **Результаты**: реакции опор, эпюры продольной силы, поперечной силы и момента, деформированная схема. Если навести курсор на стержень, видны значения в этой точке.
- **Настольный интерфейс** в одном окне с таблицами для ввода модели или работа из Python для тех, кто программирует.
- **Проекты** сохраняются в файлах `.nrv`.
