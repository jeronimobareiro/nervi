# Быстрый старт

В этом руководстве рассчитывается шарнирно опёртая балка пролётом 6 м с равномерной нагрузкой 20 кН/м. Ожидаемый максимальный момент: q·L²/8 = 20 · 6² / 8 = **90 кН·м**.

Единицы в руководстве: кН и м. Направление осей и знаки внутренних усилий описаны в разделе [Правила знаков](tecnica/convenciones.md).

## Через интерфейс

Вся работа ведётся в одном окне. Вверху находится цепочка **Геометрия › Нагрузки › Расчёт › Результаты**, слева дерево проекта, справа свойства выбранного объекта.

1. **Геометрия.** В таблице узлов задайте N1 в точке (0, 0) и N2 в точке (6, 0). В таблице стержней соедините N1 с N2 и введите E = 2.5e7, A = 0.125, I = 0.0026.
2. **Опоры.** В N1 запретите перемещения по X и Y (неподвижная шарнирная опора), в N2 запретите только Y (подвижная опора).
3. **Нагрузки.** Создайте загружение D и добавьте на стержень равномерную нагрузку qy = −20 (вниз).
4. **Расчёт.** Нажмите **F5** или кнопку **Рассчитать**. Если в модели чего-то не хватает, например опоры, вкладка **Проверка модели** подскажет, чего именно.
5. **Результаты.** Выберите эпюру **Момент**. При наведении курсора на стержень видны M, V и N в каждой точке, а в середине пролёта — максимум 90 кН·м. Реакции опор находятся в таблице внизу.
6. **Сохранение.** Ctrl+S сохраняет проект в файл `.nrv`.

Сочетанием **Ctrl+K** открывается поиск, с помощью которого можно найти любую команду или элемент модели по названию.

## Через Python

Тот же расчёт, записанный как программа:

```python
import nervi

m = nervi.Modelo()
a = m.agregar_nudo(0, 0)
b = m.agregar_nudo(6, 0)
viga = m.agregar_barra(a, b, E=2.5e7, A=0.125, I=2.6e-3)
m.apoyar(a, ux=True, uy=True, rz=False)    # неподвижная шарнирная опора
m.apoyar(b, ux=False, uy=True, rz=False)   # подвижная опора
m.carga_uniforme("D", viga, qy=-20)        # кН/м вниз
m.carga_uniforme("L", viga, qy=-10)

res = m.resolver()
d = res.combinar("D", {"D": 1.0})
print(d.diagrama(viga)["M"].max())         # 90 кН·м
print(d.reacciones[a])                     # [Rx, Ry, Mz] = [0, 60, 0]

u = res.combinar("1.2D+1.6L", {"D": 1.2, "L": 1.6})
print(u.diagrama(viga)["M"].max())         # 0.125 · 40 · 6² = 180 кН·м
```

Имена функций и аргументов написаны по-испански, на рабочем языке проекта (`Modelo` — модель, `agregar_nudo` — добавить узел, `agregar_barra` — добавить стержень, `apoyar` — задать опору, `carga_uniforme` — равномерная нагрузка, `resolver` — рассчитать, `combinar` — составить сочетание загружений). Более полный пример — рама с ветровой нагрузкой и сочетаниями — находится в [`examples/portico_simple.py`](https://github.com/jeronimobareiro/nervi/blob/main/examples/portico_simple.py).
